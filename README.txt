MiOrganizador - primera versión

Incluye:
- Tareas con prioridad, fecha y estado.
- Lista de compras con cantidad y precio opcional.
- Recordatorios con fecha y hora.
- Datos guardados localmente en el navegador del dispositivo.
- Diseño adaptable a Android y modo instalable PWA.

Limitaciones de esta versión:
- Los datos quedan guardados en el navegador/dispositivo; no se sincronizan entre equipos.
- Los recordatorios se comprueban mientras la aplicación está abierta. Para avisos fiables con la app cerrada se requiere un backend de notificaciones push.
- Para instalar como PWA se debe publicar en un hosting HTTPS (por ejemplo GitHub Pages).

Para probar:
1. Publica estos archivos en un hosting HTTPS.
2. Abre la URL desde Chrome en Android.
3. Menú de Chrome > Instalar aplicación / Añadir a pantalla de inicio.
